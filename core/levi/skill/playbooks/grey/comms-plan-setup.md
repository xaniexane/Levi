# Exercise Communications Plan Setup

## Purpose

Exercises run on communications: team channels, control nets, escalation paths, and the
schedule that keeps everyone synchronized. This setup builds the comms plan before
execution.

## When to use

- During exercise planning.
- For distributed exercises especially.

## Prerequisites

- Participant roster and roles.
- Communication tooling (chat, bridge, radio as applicable).

## Procedure

1. Define the nets: team channels, white-cell control net, observer net, emergency net.
2. Publish the communications schedule: check-ins, sync points, hot-wash timing.
3. Document escalation paths: incident → white cell → exercise director → stakeholders.
4. Test every channel before the exercise (comms check).
5. Define EMCON-style rules if the scenario needs them (when teams go quiet).
6. Hand over the comms card to every participant.

## Expected outputs

- Communications plan with nets and schedules.
- Escalation-path documentation.
- Comms-check results.

## Pitfalls

- Untested channels — the comms check is mandatory.
- No emergency net — define it before the emergency.
- Escalation paths that end in voicemail — verify humans answer.
