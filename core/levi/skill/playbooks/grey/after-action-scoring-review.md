# After-Action Scoring Review

## Purpose

The scoring model is also graded: did it measure what mattered? This after-action review
evaluates the scoring process — missed behaviors, perverse incentives, rubric gaps — and
improves the model for next time.

## When to use

- During the after-action review.
- After adjudication closes.

## Prerequisites

- Final scores and adjudication record.
- Participant feedback on the scoring.

## Procedure

1. Review each scoring element: did it discriminate good from bad performance?
2. Identify behaviors the model missed (good or bad) that should be scored next time.
3. Check for perverse incentives: did the model reward gaming over real performance?
4. Collect participant feedback on fairness and clarity.
5. Publish the scoring after-action with concrete model changes.
6. Version the scoring model for the next exercise.

## Expected outputs

- Scoring after-action report.
- Model change list.
- Versioned scoring model.

## Pitfalls

- Skipping the model's own review — the rubric rots without it.
- Defensive scoring-team posture — the review is blameless.
