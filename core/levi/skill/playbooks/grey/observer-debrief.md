# Observer Debrief Process

## Purpose

Observers see things participants miss — but only if someone asks. This debrief captures
observer notes systematically before they disperse, feeding the after-action with the
outside view.

## When to use

- Immediately after exercise execution, before observers depart.

## Prerequisites

- Observer notes package.
- Debrief facilitator and structured format.

## Procedure

1. Convene observers promptly — same day, before travel.
2. Walk the structured debrief: key moments, surprises, fairness notes, process
   observations.
3. Capture per-observer highlights and the consensus view separately.
4. Collect all notes, recordings, and artifacts into the package.
5. Identify observations needing follow-up (disputed facts, safety notes).
6. Feed the debrief output into the after-action review.

## Expected outputs

- Observer debrief record.
- Consensus and dissenting observations.
- Follow-up item list.

## Pitfalls

- Delayed debriefs — memories fade and observers leave.
- Unstructured debriefs — structure it or lose the signal.
- Observer input filed and forgotten — feed it to the after-action.

## Exercise role

The observer debrief is the exercise's outside view — captured same-day, structured, and
fed forward.
