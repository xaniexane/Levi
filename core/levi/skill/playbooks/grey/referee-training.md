# Referee Training and Calibration

## Purpose

Referees rule consistently only if they're calibrated: same charter, same scenario
understanding, same ruling philosophy. This training gets them there before execution.

## When to use

- Before exercise execution, after the charter is published.

## Prerequisites

- Referee charter and scenario.
- Ruling scenarios for calibration exercises.

## Procedure

1. Brief referees on the charter, scenario, and scoring model.
2. Run calibration scenarios: sample disputes, each referee rules, compare and discuss.
3. Align on philosophy: letter vs. spirit of the rules, safety primacy, documentation
   standards.
4. Assign referee coverage: who watches what, handoff procedures.
5. Establish the referee net and ruling-log tooling.
6. Record calibration completion; note dissent for the charter record.

## Expected outputs

- Calibration exercise results.
- Ruling-philosophy alignment notes.
- Coverage assignments.

## Pitfalls

- Uncalibrated referees — inconsistent rulings destroy trust.
- Skipping the philosophy alignment — the hard calls need shared principles.
- No coverage plan — gaps in referee presence.

## Exercise role

Calibrated referees are the exercise's judiciary — trained together, ruling alike,
before the first dispute.
