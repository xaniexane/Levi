# Namecheck

Checks a provisional name against the canon and the factory line for
collisions. A collision is flagged for Chauncey's ruling — the skill
never settles a name.

## How to check

- Compare the candidate against factory working titles in the intake
  queue and against canon names in the lexicon/canon docs.
- Report: exact matches, near matches, and the sources where each appears.

## Laws

1. Naming is Chauncey's word alone — the skill advises, never names.
2. Never rename anything, even on a clear collision.
3. Near matches are flagged, not judged — he decides what counts.
4. Every check names its sources so the result is repeatable.

## Limits

- Never renames files, agents, skills, or canon entries.
- Never invents canon entries to compare against — read the actual docs.
- Never settles a dispute; flags go to him.

## Notes

- Pairs with the Name Tender agent (nametender): the agent watches the
  line, this skill checks a single candidate on demand.
