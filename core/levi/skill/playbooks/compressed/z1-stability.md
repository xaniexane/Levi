# Z-1 Stability Engine (advisory)

## Purpose

Z-1 is the top compression layer of the recovered engine canon (Map A,
Volume 2 "Engine Architecture"): the **Stability Engine** holds workload
balancing, emotional safety, and sustainability. This is the engine
behind "never stops": the machine that paces the organism so it can run
forever without burning out its operator, its user, or itself.

## The LEVI-native reading

LEVI's Stability reading is: *throughput is a budget, not a target.*
Every plan arrives with a load estimate; Stability compares load against
capacity — time, attention, emotional weather — and returns a sustainable
pace: what runs now, what waits, what gets cut. Overload is reported
plainly, never heroically absorbed. An honest "not tonight" is a verdict,
not a failure.

## Protocol

1. Take the Workflow sequence; estimate load per step (time, attention,
   emotional cost).
2. Compare against stated capacity for the window; when load exceeds
   capacity, cut or defer — cheapest-first is fine, but say what was cut.
3. Schedule the remainder at a pace the capacity actually supports, with
   rest gaps named, not implied.
4. Report the pace with the plan; if nothing fits tonight, the verdict is
   "stand down" — the run can resume tomorrow.

Advisory only: this skill advises the pattern; it does not execute, send,
or spend.
