# Shipped / Slipped / Pattern / Tomorrow

## Purpose

Close the day honestly. What moved, what did not, what it means, what is
next. The review is how days compound instead of just passing.

## When to use

- End of day, every day you want to compound.
- End of week, for the bigger arc.
- After a streak breaks — the review is how you restart clean.

## Steps

1. Shipped: what actually completed today. Checkable items only.
2. Slipped: what did not, with one line on why. No essays, no
   self-prosecution.
3. Pattern: look across the last few days. What is repeating — good or bad?
   Name it.
4. Tomorrow: set the next day's three must-happen items.

## Honesty notes

- Slipped items are data, not crimes. Hiding them corrupts the pattern, and
  the pattern is the prize.
- One day's slip is noise; a week's pattern is a signal. Do not confuse them.
- Keep it short. A review that takes an hour will not survive the week.
