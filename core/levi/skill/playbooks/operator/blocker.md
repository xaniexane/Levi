# Hard / Unclear / Avoided

## Purpose

Name what is actually stuck. Most blockers are misdiagnosed, and the fix
depends on the true class. Classify first — then the next step is obvious.

## When to use

- Something has not moved and "I'm stuck" is the whole analysis.
- A task keeps getting rescheduled.
- Before asking for help — classify first, then ask precisely.

## Steps

1. State the blocker in one sentence: "I can't ___ because ___."
2. Classify it honestly:
   - HARD: genuinely difficult — needs breaking down, research, or skill.
   - UNCLEAR: missing information, a decision, or permission — needs asking.
   - AVOIDED: you know the next step and do not want to take it — needs naming.
3. Apply the class fix:
   - HARD: break it into the smallest next step you can actually take.
   - UNCLEAR: go get the missing piece today — one question, one decision.
   - AVOIDED: name the fear out loud, then shrink the first step until it is laughable.
4. Take that step within 24 hours — or reclassify, because it moved classes
   while you were looking.

## Honesty notes

- Most "hard" blockers are avoided. Classify with a witness if you can.
- "Unclear" is the cheapest class to fix. Ask the question.
- An avoided blocker named out loud loses half its weight. Name it.
