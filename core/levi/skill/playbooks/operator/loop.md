# The Shipping Loop

Composite: ship × review × streak (absorbed 2026-09-29).

## Purpose

Shipping is a decision with a definition, not a feeling — and one shipped
thing means nothing without the loop that repeats it. ① Define done and
ship. ② Close the day honestly. ③ Keep the streak alive. The loop is how
days compound instead of just passing.

## When to use

- "Almost done" has lasted longer than the first 90% took.
- End of day, every day you want to compound — and after a streak breaks.
- Building a daily practice: shipping, writing, deep work.

## Steps

1. ① Define done: observable, checkable by someone else. "It works" is not
   a definition. Freeze scope — nothing new enters; new ideas go on a
   next-version list.
2. List the remaining moves to done — concrete, countable — execute in
   order, verify against the definition, then declare it shipped. Out loud.
3. ② Close the day: shipped (checkable items only), slipped (one line on
   why — data, not crimes), pattern (what repeats across days — name it),
   tomorrow (the next day's three must-happen items).
4. ③ Keep the streak: define what counts as a streak day — one checkable
   criterion, written down. Record daily, binary: it continues or it does
   not. When it breaks, note the cause in one line and restart the next day.
5. Milestones (7, 30, 100) are for noticing, not pressure. Never let the
   streak outrank the work — a streak preserved by lowering the bar is a
   lie with a number on it.

## Honesty notes

- Done must survive an independent check. If only you can tell, it is not done.
- One day's slip is noise; a week's pattern is a signal. Do not confuse them.
- The only rule after a break is restart. Guilt is not a strategy.
- Ship, then improve. Version two exists because version one shipped.
