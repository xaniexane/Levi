# Sprint Design

## Purpose

Design a single deep-work block that actually stays deep — one objective, a
start ritual, and a distraction contract. Ninety focused minutes beat four
fragmented hours.

## When to use

- Before any work that needs sustained focus.
- When "I'll focus today" keeps dissolving by mid-morning.
- After setting the day's three, to give the hardest one its protected block.

## Steps

1. One objective for the block. Write it as a done-state: "By the end,
   ___ exists / works / is decided."
2. Set the start ritual: the same two-minute sequence every time, the signal
   that tells your brain it is go-time.
3. Write the distraction contract: phone where, notifications off, tabs
   closed, people notified. In writing, before the block starts.
4. Define the single exit condition: the block ends when the objective is met
   or the timer ends — not when boredom arrives.
5. Schedule it like an appointment with someone you respect. Protect it like one.

## Honesty notes

- A deep block without a distraction contract is a calendar entry, not a
  commitment.
- If the block gets interrupted, the ritual restarts it. That is what the
  ritual is for — use it instead of mourning the interruption.
- Multitasking inside a deep block is just fragmentation with a nicer name.
