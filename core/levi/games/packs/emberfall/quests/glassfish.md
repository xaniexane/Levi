# Quest: The Glassfish Run

Spring tide is coming. Pip knows a pool that nobody has fished — or so
she claims, while selling the map to it for the third time this week.

Catch a sack of glassfish before the tide turns. Sable pays on delivery,
no questions. Mira Salt pays half as much and writes your name in the
public ledger under "honest work," which in Emberfall is worth more than
it sounds.

The clear ones are the quick ones.
