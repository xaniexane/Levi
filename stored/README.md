# stored/

Work that was removed from the main tree lives here — stored for later use
or review, never deleted. (Standing law, Chauncey 2026-09-21: nothing is
ever thrown away.)

Convention: `stored/<date>-<what>/`, e.g. `stored/2026-09-21-vscode-extension/`.
Each folder keeps a note saying why it was moved out of the tree and where
it came from.
