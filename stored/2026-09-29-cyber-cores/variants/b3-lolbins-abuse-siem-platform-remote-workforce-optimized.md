# Living-off-the-Land Binaries Abuse Defense for SIEM Platforms in Remote Workforce (Optimized Maturity)

## Purpose

Attackers use built-in tools (certutil, bitsadmin, mshta, rundll32, wmic) for download, execution, and exfiltration — no malware to signature. Defense is behavioral: baseline normal LOLBin usage and alert on anomalous parents, arguments, and network activity. Applies to SIEM Platforms in Remote Workforce at Optimized maturity.

## When to use

- LOLBins spawned by Office apps, browsers, or scripts with network arguments (certutil -urlcache, bitsadmin /transfer) — parents that never legitimately drive them.
- Encoded or obfuscated arguments, downloads to temp/appdata, or LOLBin-initiated outbound connections.
- Rare LOLBins (mshta, regsvr32, cmstp) executing at all in environments that never use them legitimately.
- Lens: Best telemetry: ingestion health metrics + rule-hit history + analyst audit trail. EDR on every endpoint as the primary sensor (no corporate network tap for remote hosts).

## Prerequisites

- Written authorization from the asset owner and incident commander before active containment.
- Access to VPN/ZTNA access logs and SaaS/IdP sign-in logs as the network-visibility substitute.

## Procedure

1. **Authorize and scope.** Open a ticket, confirm written authorization, and preserve evidence before changing anything.
2. **Detect and collect.** Hunt the signals above in Detection rule hit history for the incident's indicators across the full retention window and Ingestion gap reports: which sources stopped logging and when (coverage blind spots); run `# conceptually (SIEM query languages differ):` then `index=* <indicator> earliest=-30d | stats count by sourcetype`.
3. **Analyze.** Reconstruct the full command line — the arguments reveal intent (download URL, payload path, execution method). Then: Check whether the LOLBin fetched a second stage; if so, the investigation continues at the downloaded payload.
4. **Contain and harden.** Application control policies blocking LOLBin network/download primitives where unused; constrained language mode for PowerShell. Asset layer: Separate SIEM admin credentials, tamper-evident storage, monitored ingestion pipelines. Environment layer: Zero-trust access: device compliance + MFA per application, not per network.
5. **Document and improve.** Feed incident lessons back into detection-as-code within one sprint — the playbook is a living document, not a PDF. Record the timeline, indicators, actions taken, and lessons learned.

## Expected outputs

- Scoped timeline; affected assets, accounts, and data with containment status each.
- Hardening verified effective; detection improvements filed.

## Pitfalls

- Blocking a LOLBin outright and breaking admin workflows — constrain by parent and argument, not by existence.
- Missing LOLBin use on Linux/macOS (curl, wget, python) while hunting Windows only.
