# Owners + Deadlines

## Purpose

Turn notes, meetings, and conversations into commitments. Every action gets
one owner and one deadline — or it gets dropped. An action without both is
a wish someone else will fulfill.

## When to use

- After any meeting, call, or long thread.
- On pasted notes that "contain action items."
- Weekly, to sweep for orphaned intentions.

## Steps

1. Extract every implied action from the notes — including the ones phrased
   as observations. "We should" is hiding an action.
2. Each action gets exactly one owner: a name, never a group. Groups own
   nothing.
3. Each action gets a deadline: a date, not "soon."
4. Anything that cannot get an owner and a deadline gets dropped, explicitly.
5. Read the list back. If an owner would not recognize their item, rewrite it
   until they would.

## Honesty notes

- "We should" is not an action. Convert it or cut it.
- Fewer, owned actions beat a long list of hopes every time.
- The dropped list is a feature. It proves the extraction was honest.
