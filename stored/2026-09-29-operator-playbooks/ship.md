# Define Done, Freeze Scope

## Purpose

Turn "almost done" into shipped. Shipping is a decision with a definition,
not a feeling. Most things that never ship were never defined as done.

## When to use

- A task has been "90% done" for longer than the first 90% took.
- Scope keeps growing mid-flight.
- Before calling anything finished.

## Steps

1. Write the definition of done: observable, checkable by someone else.
   "It works" is not a definition.
2. Freeze scope. Nothing new enters. New ideas go on a next-version list,
   not into this ship.
3. List the remaining moves to reach done — concrete, countable.
4. Execute the moves in order. No detours, no "while I'm here."
5. Verify against the definition, then declare it shipped. Out loud.

## Honesty notes

- Done must survive an independent check. If only you can tell it is done,
  it is not done.
- Freezing scope is the hard part. The freeze is what makes shipping possible.
- Ship, then improve. Version two exists because version one shipped.
